## 핵심 개념

- `max(iterable, key=lambda x: ...)` 람다에게 값을 하나씩 넘겨 결과적으로 최고 결과값을 반환 
- 계층적 상태 전파 : 센서의 상태값들만 모은 리스트를 만듬 -> max() 함수에서 키맵핑으로 최고위험 상태값 찾아 장치의 상태값으로 반영 

## 발견한 문제

- * `validate_device(value)` 함수에 `value`로 `True`를 전달했을 때 타입 검사(`isinstance(value, (int, float))`)를 통과하고 범위 검사(`-1000 <= 1 <= 1000`)까지 참이 되어, 올바르지 않은 불리언 값이 정상 측정값으로 처리됨.
