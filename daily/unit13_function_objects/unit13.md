# Unit 13 - 함수 객체와 고차 함수

## 오늘의 목표

- 함수를 데이터처럼 다루면 코드 구조를 어떻게 바꿀 수 있는가

## 구현할 함수 목록 

- classify_status, build_measurement, create_classifer


## 핵심 개념

- 함수도 객체
  - 센서별 실행할 함수를 매핑 테이블처럼 만들어 쓸 수 있다
  - 확장성, 가독성, 성능에 유리 할 수 있다 다만, 논리가 복잡하거나 확장할 일이 없다면 조건문을 써도 됨 
- 고차 함수
  - 함수를 인자로 받아, 여러 규칙마다 작성할 필요없이, 동일한 처리 흐름으로 규칙은 외부에 맡겨버림
  - 처리흐름이 같은 함수를 여러개 생성할 때, 함수를 리턴하는 함수를 작성할 수 있다. 
  - 클로저: 리턴되는 함수의 외부 값(생성 함수의 매개 변수)를 기억하고 있는 것 

## 발견한 문제

- 임계값을 변경하게된다면, 기존 판정들은 어떻게 할까?
- 당시 판정 기록이 중요하면 판정값을 저장하거나, 그게 아니라면 측정값만 저장하고 상태는 조회할 때 계산
- 또, 그것과 별개로 임계값 변경 이력을 관리할 수 있음
