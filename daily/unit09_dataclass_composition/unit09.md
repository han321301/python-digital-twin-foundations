# Unit 09

## 오늘의 목표

- 단일 센서 클래스를 확장해서 장치가 여러 센서 객체를 관리하는 구조 만들기

## 핵심 개념

- @dataclass : __init__ 과 같은 메서드 자동 생성해주며 간편하게 작성하게 해줌
- 클래스 기본값으로 리스트와 딕셔너리 지정 불가, `dict[str, dict] = field()` 
- 합성 관계(디바이스 - 센서의 느슨한 결합) > 상속 관계 

## 발견한 문제

필터링에서 두 가지 방식 
1. `target_id not in dict_obj` 
- 키의 존재로만 판단하기 때문에 안전하고 빠르다 

2. `dict_obj.get(target_id) is None`
- 키의 값이 None인지 키 자체가 존재하지 않는건지 구별 못함 = 위험함 
- 값까지 조회하기 때문에 더 느림 
 
## 오늘의 결론

- 단순히 키로 존재 유무만 알고 싶다면 get()을 쓰지 않는게 좋음 
- 값까지 확인(값이 None인 경우인지)해야하는 경우라면 get()
