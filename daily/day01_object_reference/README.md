# Day 01: 객체, 참조, 가변성

## 오늘의 목표

- 이름과 객체의 차이를 설명한다.
- 재할당과 객체 변경을 구분한다.
- 얕은 복사와 깊은 복사의 차이를 확인한다.

## 실용 예제

장비 상태를 생성하고 측정값을 추가한다.

## 핵심 개념

- mutable / immutable
- aliasing
- shallow copy
- deep copy
- side effect

## 발견한 문제

`dict.copy()`는 내부 리스트까지 복사하지 않는다.

## 오늘의 결론

중첩된 상태를 복사할 때는 내부 객체의 공유 여부를 확인해야 한다.
