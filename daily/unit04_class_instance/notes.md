# Day 4

## 오늘의 목표

- 기존의 센서 딕셔너리를 클래스로 변환하여 비교
                             

## 구현할 함수 목록 

- `Sensor` 클래스와 인스턴스 생성


## 핵심 개념

- 클래스는 생성 구조를 통일하고, 데이터와 관련 동작을 묶을 수 있다.필수 키를 강제할 수 있다. 
- 단순 데이터에는 구조가 과할 수 있다. JSON으로 바로 저장할 수 없다. 

## 발견한 문제

- 리스트는 `__init__`에서 선언하지 않음 (모든 인스턴스가 공유해버리는 버그 발생)
- `self.name = name or sensor_id` name이 None이 아닌 0, "", False인 경우에도 sensor_id를 할당해버림 
- `self.name = sensor_id if name is None else name` 으로 작성해야 None만 구분 가능 


## 오늘의 결론
- 데이터와 동작이 묶여서 여러 개가 독립적으로 돌악야 할 때 클래스를 고려한다.
