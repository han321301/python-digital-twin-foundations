# Python Digital Twin Foundations

디지털트윈 개발에 필요한 Python 핵심 개념을 장비 상태 관리와 센서 데이터 처리 예제로 학습하는 14일 프로젝트입니다.

각 일차에는 하나의 실용 예제를 중심으로 개념을 확인하는 `concepts.py`와, 학습 내용을 통합해 구현하는 `task.py`를 작성합니다.

## 학습 목표

* Python 객체, 참조, 자료구조 이해
* 조건문, 반복문, 함수 설계 학습
* 센서 로그 파싱과 데이터 검증
* 예외 처리와 파일·JSON 입출력
* 클래스, 제너레이터, 모듈, 테스트 학습

## 학습 구조

daily/
└── dayXX_topic/
    ├── README.md    # 목표, 개념, 학습 기록
    ├── concepts.py  # 개념 실험과 코드 비교
    └── task.py      # 최종 구현 과제와 assert 검증

## 최종 결과물

학습 과정에서 작성한 코드를 다음 두 모듈로 정리합니다.

```text
src/
└── digital_twin_learning/
    ├── device_manager.py
    └── sensor_processor.py
```

* `device_manager.py`: 장비 생성, 측정값 관리, 상태 판정 및 조회
* `sensor_processor.py`: 센서 로그 파싱, 검증, 일괄 처리 및 파일 저장
